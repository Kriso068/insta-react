# PixSphere — Social Media UI (React + Vite)

PixSphere is a **social media UI concept** inspired by modern photo-sharing platforms.
This project was built using **React**, **Vite**, **Chakra UI**, and **Firebase**, with a focus on **front-end architecture**, **authentication flows**, and **responsive design**.

⚠️ **Disclaimer**  
This project is a **personal portfolio and learning project**.  
It is **not affiliated with Instagram, Meta, or any other social media platform**.  
All names, visuals, and features are used for demonstration purposes only.

---

## 🚀 Technologies Used
- React
- Vite
- Chakra UI
- Firebase (Authentication & Database)
- JavaScript (ES6+)
- HTML5
- CSS-in-JS

---

## 🎯 Project Goals
- Build a modern social media-style interface
- Implement authentication using Firebase
- Practice component-based architecture with React
- Create a responsive and accessible UI using Chakra UI
- Simulate core social platform features for learning purposes

---

## 🧩 Features
- User authentication (Firebase Auth)
- Login and sign-up UI
- Responsive layout (desktop & mobile)
- Reusable UI components with Chakra UI
- Clean and modular code structure
